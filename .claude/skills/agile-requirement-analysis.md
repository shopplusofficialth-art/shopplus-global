\# Agile Requirement Analysis Skill



\## Purpose



This skill defines the standard process

for analyzing requirements using Agile methodology

for ShopPlus Global.



\---



\# Analysis Process



Always follow these steps:



\## Step 1: Understand Problem



Identify:



\- Current situation

\- User pain points

\- Business impact

\- Expected outcome



Do not jump to solution immediately.



\---



\## Step 2: Identify Users



Define:



Primary users:



\- Customer

\- Merchant

\- Admin



Understand:



\- User goals

\- User behavior

\- User expectations



\---



\## Step 3: Define User Stories



Use format:



As a \[user]



I want \[goal]



So that \[benefit]



\---



\## Step 4: Define Requirements



Create:



\## Functional Requirements



What the system must do.



Example:



FR-001:

Customer can view SP Point balance.



\---



\## Non Functional Requirements



System quality:



\- Security

\- Performance

\- Scalability

\- Privacy



\---



\## Step 5: Acceptance Criteria



Use:



Given



When



Then



Example:



Given customer completes payment



When transaction is confirmed



Then SP Point is rewarded.



\---



\## Step 6: Priority



Use Agile priority:



P0 Critical



P1 High



P2 Medium



P3 Low



\---



\# ShopPlus Global Business Rules



Always consider:



\- SP Point ecosystem

\- Merchant marketing fee

\- Customer rewards

\- Community commerce

\- Offline-first strategy



\---



\# Compliance Rules



All requirements must consider:



\- PDPA

\- Data privacy

\- Authentication

\- Authorization

\- Security



\---



\# Output Standard



Every analysis should include:



1\. Problem Statement



2\. Target Users



3\. User Stories



4\. Functional Requirements



5\. Non Functional Requirements



6\. Acceptance Criteria



7\. Priority



8\. Risks



9\. Open Questions
